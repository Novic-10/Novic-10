Executive Summary & Overview

This challenge involved investigating network activity using Wireshark to identify suspicious communications, malware families, and associated MITRE ATT&CK techniques. The analysis focused on four distinct PCAP files, each presenting a unique scenario ranging from SSH data transfers to DNS exfiltration attempts. Key tasks included identifying remote IP addresses, calculating data transfer volumes, performing OSINT on suspicious IPs to uncover malware infrastructure, and mapping observed activities to specific ATT&CK techniques and sub-techniques.

Key Takeaways & Security Insights

  • •
    Importance of ASN Mapping: Identifying Autonomous System Numbers (ASNs) for IP addresses is crucial. While an IP address provides a location, the ASN reveals the organization or entity that owns the IP range, offering valuable context for threat intelligence and attribution.
  • •
    OSINT for Threat Intelligence: Leveraging Open-Source Intelligence (OSINT) tools and databases (e.g., VirusTotal, IP reputation services) is essential for correlating suspicious IPs with known malware families (Trickbot, miner) and historical attack campaigns.
  • •
    MITRE ATT&CK Framework: The MITRE ATT&CK framework provides a standardized taxonomy for describing adversary tactics and techniques. Mapping observed network activity to specific techniques like T1496 (Resource Hijacking) or sub-techniques like T1071.004 (DNS for Command and Control) is vital for understanding adversary behavior and developing effective defenses.
  • •
    Network Traffic Analysis with Wireshark: Wireshark remains an indispensable tool for deep packet inspection, allowing analysts to identify unusual ports, protocols, data transfer volumes, and timing anomalies that can indicate malicious activity.
