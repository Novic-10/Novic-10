Executive Summary & Overview

This challenge involved analyzing network traffic and Splunk logs to reconstruct an attacker's activities, from initial web server compromise to full domain-wide control. The investigation revealed a multi-stage attack chain, beginning with the exploitation of a web server to exfiltrate sensitive credentials.

Subsequently, the attacker leveraged these credentials to gain access to an Active Directory-joined workstation, DESKTOP-2FII9FV. On this system, tools like certutil.exe were used to download malicious binaries, including Mimikatz (disguised as Troubleshooter.ps1 and svch0st.exe). The attacker then executed Mimikatz via powershell.exe to dump credentials and ultimately perform a Golden Ticket attack, achieving full domain compromise of highlysecured.tech.

Reasoning: This specific Kerberos ticket file was observed being used in conjunction with Mimikatz for a pass-the-ticket attack, indicating lateral movement.

12. It is believed that the attacker has achieved domain-wide compromise. What technique was used? (Format: Xxxxxx Xxxxxx)

Golden Ticket

Reasoning: The use of Mimikatz to forge a Kerberos Ticket Granting Ticket (TGT) for the krbtgt account signifies a Golden Ticket attack, leading to domain-wide compromise.

Reasoning: This specific Mimikatz command, found in Splunk logs, was used to generate and inject the Golden Ticket, specifying the user, domain, SID, krbtgt hash, and ID.

Key Takeaways & Security Insights

  • •
    Web Server Security: Initial compromise often targets web-facing applications. Robust input validation, regular patching, and strong access controls are crucial to prevent command injection and file exfiltration.
  • •
    Credential Management: Storing sensitive credentials (like Mike Tyson : P@55w0rd) in plain text files (.credentials.txt) is a critical vulnerability. Implement secure credential storage solutions and enforce strong password policies.
  • •
    Endpoint Detection & Response (EDR): Tools like Sysmon are invaluable for detecting suspicious process creation, file downloads (e.g., certutil.exe), and execution of known malicious tools (Mimikatz).
  • •
    Active Directory Hardening: Attacks like Golden Ticket demonstrate the severe impact of krbtgt account compromise. Implement strict security for domain controllers, monitor for suspicious Kerberos activity, and regularly rotate the krbtgt password.
  • •
    Log Analysis with Splunk: Centralized logging and powerful SIEM solutions like Splunk are essential for correlating events across multiple systems, identifying attack patterns, and tracing attacker movements. Effective queries can quickly pinpoint critical indicators of compromise.
