This writeup details the analysis of a sophisticated phishing campaign attributed to the Kimsuky (APT43) threat group. The incident began with a user, Wendy, receiving a malicious .MSC file, Financial_Report_2024.MSC, which initiated an infection chain.

The attack leveraged a PowerShell command to download a payload from a C2 server (192.168.42.131), which was initially detected by Windows Defender as Trojan:Win32/SuspGolang.AG. Persistence was established via a scheduled task named OneDrive Security Task, and the threat actors utilized Sliver C2 for command and control.

Post-compromise activities included domain reconnaissance using utilities like nltest.exe and net.exe, followed by LSASS credential dumping. The attackers successfully moved laterally to the domain controller (dc-01) using the Administrator account and established remote access via code.exe tunnel, demonstrating a full compromise lifecycle.

Question & Answer Solutions

1. A user received a phishing email containing a zip file, which included a malicious attachment. Upon interaction with the file, the infection chain was initiated. Identify the name of the compromised user.

Wendy

Reasoning: The user Wendy was identified as the recipient of the phishing email and the initial point of compromise, as indicated in the incident details.

2. The file type has been abused by the threat group Kimsuky (aka APT43, Velvet Chollima) since April 2024. Provide the name of the malicious file.

Financial_Report_2024.MSC

Reasoning: Open-source intelligence (OSINT) on Kimsuky's recent tactics, techniques, and procedures (TTPs) revealed their use of .MSC files for initial access. The specific file name was found in the initial infection artifacts.

3. When the user clicked the link in the malicious file, a PowerShell command was triggered to download a payload from a command-and-control (C2) server. Provide the IP address of the C2 server.

192.168.42.131

Reasoning: The C2 IP address was identified in registry persistence logs, which recorded the PowerShell command attempting to download the payload.

4. The payload was initially blocked by Windows Defender antivirus. Name the signature of the threat.

Trojan:Win32/SuspGolang.AG

Reasoning: Windows Defender event logs, specifically Event ID 1116, showed the malware being detected and quarantined with the signature Trojan:Win32/SuspGolang.AG.

5. The file establishes persistence by creating a scheduled task. Provide the name of this scheduled task.

OneDrive Security Task

Reasoning: Analysis of Defender rule names and scheduled task configurations revealed a newly created task named OneDrive Security Task, indicating persistence.

6. Identify the name of the command-and-control (C2) tool used by the threat actors to manage their malicious operations.

Sliver C2

Reasoning: The C2 framework was explicitly named in the triggered security rules and alerts, indicating the use of Sliver C2.

7. A few minutes after the initial infection, the threat actor engaged in hands-on keyboard activity for domain reconnaissance. Specify the timestamp (in UTC) for the first executed command.

2024-10-04 15:34:20

Reasoning: By reviewing event logs for network discovery commands (e.g., net.exe, nltest.exe), the earliest timestamp for such activity was identified.

8. This was followed by the dumping of the LSASS process using the initial C2 implant. Provide the process ID of the source process.

10840

Reasoning: Security rules and alerts specifically flagged a process with PID 10840 (associated with C:\OneDrive.exe) attempting to dump LSASS credentials.

9. During their discovery activities within the network using Windows utilities like nltest.exe and net.exe, the threat actor found a privileged user's login session (informed in the scenario). To escalate their privileges and bypass defenses, the attacker injected a command-and-control (C2) implant into a legitimate process. Identify the process ID.

9056

Reasoning: Filtering logs for activity related to the privileged user Ruth and C2 implant activity revealed a process with PID 9056 as the target for injection.

10. The threat actor attempted to move laterally to the domain controller. During the initial attempt, the service was detected by Windows Defender AV. Provide the name of the service.

Intune

Reasoning: Windows Defender AV logs showed a detection related to the Intune service during the initial lateral movement attempt towards the domain controller.

11. The threat actor ultimately succeeded in pivoting to the domain controller. Identify the name of the account used by the attacker for this action.

Administrator

Reasoning: Event logs on the domain controller indicated successful authentication and activity using the Administrator account, confirming its use for lateral movement.

12. The attacker returned to the beachhead and attempted to execute commands using a popular IDE platform. This technique was recently used by a Chinese Advanced persistent threat (APT) group to carry out cyber espionage attacks. Provide the executed command.

code.exe tunnel

Reasoning: Analysis of process execution logs on the beachhead system revealed the command code.exe tunnel, which is known to establish remote access under the SYSTEM account, a technique observed in recent APT attacks.

Key Takeaways & Security Insights

  • •
    Phishing Awareness: The initial compromise of user Wendy via a malicious .MSC file highlights the critical need for robust user awareness training and email security solutions to detect and block such threats.
  • •
    Defense Evasion & Persistence: Threat actors continue to abuse legitimate file types (.MSC) and establish persistence through scheduled tasks (e.g., OneDrive Security Task). Organizations must implement strong application whitelisting and monitor scheduled task creation.
  • •
    C2 Frameworks & Detection: The use of Sliver C2 emphasizes the need for network intrusion detection systems (NIDS) and endpoint detection and response (EDR) solutions capable of identifying known C2 beaconing patterns and suspicious process behaviors.
  • •
    Credential Dumping & Lateral Movement: LSASS credential dumping (PID 10840) remains a critical post-exploitation technique. Implementing credential protection, privileged access management (PAM), and monitoring for suspicious access to sensitive processes is crucial.
  • •
    Domain Reconnaissance: Attackers frequently use built-in Windows utilities like nltest.exe and net.exe for network discovery. Behavioral analytics and logging of command-line executions are vital for early detection.
  • •
    Endpoint Protection Effectiveness: Windows Defender successfully detected the initial payload (Trojan:Win32/SuspGolang.AG) and a lateral movement attempt (Intune service), underscoring the importance of keeping AV/EDR solutions updated and properly configured.
  • •
    Advanced TTPs: The use of code.exe tunnel for remote access under the SYSTEM account demonstrates sophisticated post-exploitation techniques. Monitoring for unusual process execution and network connections from unexpected binaries is crucial.
