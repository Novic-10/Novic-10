Executive Summary & Overview

Our detection team reported that they received an IDS alert related to reconnaissance, but they were unable to read the traffic as it was encrypted. This writeup details the analysis of provided PCAP files using tools like NetworkMiner and Wireshark to identify the exploit attempts, scanning activities, command-and-control infrastructure, and compromised credentials.

Question & Answer Solutions

1. According to Network Miner, what exploit attempt is being made on what protocol?

EternalBlue, SMB

Reasoning: This information was found by navigating to the "Anomalies" tab within NetworkMiner, which automatically identifies known exploit attempts.

2. What is the IP address of the machine responsible that is conducting network scanning using Nmap?

172.16.0.5

Reasoning: Analysis of packet counts revealed that 172.16.0.5 sent the most packets, indicative of scanning activity. This was further confirmed by observing Nmap traffic originating from this IP.

3. Identify the Command-and-Control server. What is the hostname, MAC address, and listening port numbers?

IE11WIN8_1, 080027FEEC1E, 4782, 139

Reasoning: The C2 server was identified by analyzing network flows and connections. The hostname IE11WIN8_1, MAC address 080027FEEC1E, and listening ports 4782 and 139 were extracted from the network traffic.

4. What are the banking credentials of the victim?

christiww007, christismoneyworld$$

Reasoning: These credentials were found in cleartext within HTTP POST requests made to a 171.x.x.x IP address, specifically during a login attempt. The provided SSL keys allowed for decryption of the traffic.

5. What is the observed NTLM Response for the challenge from VICTIM Machine

46E55566E4DF5613

Reasoning: The NTLM response was extracted from the network capture, specifically from the authentication handshake between the victim machine and a server.

Key Takeaways & Security Insights

  • •
    NetworkMiner Efficiency: NetworkMiner significantly streamlines network analysis by automatically parsing PCAP files, extracting credentials, hosts, and anomalies, reducing the need for manual Wireshark deep dives for initial reconnaissance.
  • •
    PCAP vs. PCAPNG: Be aware of tool limitations; the free version of NetworkMiner only supports PCAP files, necessitating conversion from PCAPNG if that's the capture format.
  • •
    Cleartext Credential Exposure: Even with encrypted traffic, if SSL keys are compromised or provided, sensitive information like banking credentials can be easily recovered from HTTP POST requests, highlighting the importance of secure communication protocols and robust key management.
  • •
    Prioritizing Evidence: When investigating credentials, always prioritize direct evidence like cleartext HTTP POST requests over attempting to crack hashed credentials (e.g., SMB credentials), as the former provides immediate and undeniable proof.
