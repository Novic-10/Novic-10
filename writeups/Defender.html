Executive Summary & Overview

This writeup details the investigation into a potential compromise involving Microsoft Defender Antivirus. While Microsoft Defender offers robust protection, its configuration can be tampered with by an attacker with administrative privileges. This analysis focuses on leveraging Event Viewer logs, Command Prompt queries, and Registry Editor to uncover footprints of such tampering. The objective was to identify specific modifications made to Defender settings, including log paths, excluded extensions and directories, controlled folder access status, and disabled protection mechanisms, providing insights into potential adversary techniques (T1562.001).

Asset Information

HOSTNAME SUMMARY
BTL1 Windows system targeted for Microsoft Defender Antivirus analysis.

Question & Answer Solutions

1. What is the ‘Log Path’ for Windows Defender logs? (Format: log\path\directory\file.evtx)

%SystemRoot%\System32\Winevt\Logs\Microsoft-Windows-Windows Defender%4Operational.evtx

Reasoning: Default paths were not accepted; the actual file properties for the Operational.evtx log had to be checked.

2. What are the extensions excluded in Windows Defender? (Format: extension1, extension2)

.bat,.ps1

Reasoning: These extensions, .bat and .ps1, were likely excluded by an attacker to prevent scanning of malicious scripts.

3. What is the excluded directory, when was the event logged? (Format: drive:\path\directory, M/DD/YYYY h:mm:ss am/pm)

C:\Windows\Temp, 07/16/2021 7:11:53

Reasoning: EventID 5007 corresponded to changes in the configuration file, revealing the excluded directory C:\Windows\Temp and the timestamp.

4. Is controlled folder access enabled? What mode is it in? (Format: XxxxxXxxx)

AuditMode

Reasoning: Investigation of Controlled Folder Access settings showed it was enabled in AuditMode.

5. What is the symbolic name for the Event ID 5001? (Format: symbolic_name)

MALWAREPROTECTION_RTP_DISABLED

Reasoning: Referenced Microsoft Defender Antivirus event ID documentation to find the symbolic name for Event ID 5001.

6. The adversaries can remove all the Windows Defender Antivirus signatures using the command, "\some\path" -RemoveDefinitions -All (Complete the command) (Format: "\some\path" -RemoveDefinitions -All)

"C:\Program Files\Windows Defender\MpCmdRun.exe" -RemoveDefinitions -All

Reasoning: The full path to the MpCmdRun.exe utility is required to execute the command to remove all Defender definitions.

7. What registry key is modified when script scanning is disabled for Microsoft Defender Antivirus? (Format: path\to\registry)

SOFTWARE\Microsoft\Windows Defender\Real-Time Protection

Reasoning: The specific registry key that controls Real-Time Protection settings, including script scanning, is located at SOFTWARE\Microsoft\Windows Defender\Real-Time Protection.

8. What event id is logged if the following powershell command is executed but blocked by tamper protection mechanism? Command: Set-MpPreference -DisableScriptScanning $true (Format: eventID)

5013

Reasoning: When tamper protection blocks a command like Set-MpPreference -DisableScriptScanning $true, Event ID 5013 is logged.

9. Microsoft Active Protection Service was disabled at some point. What is the value for the field ‘New Value’ in the log? (Format: value)

HKLM\SOFTWARE\Microsoft\Windows Defender\SpyNet\SpyNetReporting = 0x0

Reasoning: The log entry for disabling Microsoft Active Protection Service (MAPS) showed the New Value for SpyNetReporting was set to 0x0.

10. What is the processID and ThreadID that disabled IOAV protection in Microsoft Defender Antivirus? (Format: processID, threadID)

7072, 6948

Reasoning: Event logs indicated that IOAV protection was disabled by ProcessID 7072 and ThreadID 6948.

11. What is the command prompt command to query the registry for excluded processes in Windows Defender Antivirus? (Format: reg query “\path\”)

reg query "HKLM\SOFTWARE\Microsoft\Windows Defender\Exclusions\Processes"

Reasoning: The reg query command is used to retrieve registry values, and the specific path for excluded processes in Windows Defender is HKLM\SOFTWARE\Microsoft\Windows Defender\Exclusions\Processes.

Key Takeaways & Security Insights

  • •
    Exclusion Impact: Understanding how Microsoft Defender Antivirus exclusions work is critical. When file extensions or directories are excluded, Defender completely bypasses scanning for those specific types or locations, creating significant blind spots for attackers. The registry key HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows Defender\Exclusions\Extensions is a key area for forensic investigation.
  • •
    Event Log Analysis: Microsoft Defender Antivirus generates detailed event logs that are invaluable for detecting tampering. Specific Event IDs (e.g., 5001 for RTP disabled, 5007 for config changes, 5013 for tamper protection blocks) provide clear indicators of compromise or attempted evasion. Regular monitoring of these logs is essential.
  • •
    Registry Forensics: The Windows Registry is a primary target for attackers seeking to disable or modify security features. Knowing the relevant registry paths for Defender settings (e.g., Real-Time Protection, SpyNet, Exclusions) allows for direct investigation of configuration changes.
  • •
    Tamper Protection: Tamper protection is a critical defense mechanism. Even if an attacker attempts to disable Defender features via PowerShell, tamper protection can block these actions and log the attempt, providing valuable alerts for defenders.
