Executive Summary & Overview

This challenge involved a digital forensics investigation into a user's Steam installation, which was located in a non-standard directory. The objective was to uncover details about the user's gaming habits, account information, and potential anti-forensic activities, based on the premise that a pet dog might be secretly playing games on the computer. The investigation required analyzing various configuration files and user data within the Steam directory structure.

Key aspects of the challenge included identifying installed games, the primary user account, associated metadata, and evidence of file manipulation within the Steamapps directory.

Key Takeaways & Security Insights

  • •
    OSINT for User Profiling: Publicly available information on platforms like Steam can reveal extensive details about a user, including their persona, real name, location, and gaming history. Tools like steamcommunity.com/profiles, steamhistory.net, steamid.io, steamladder.com, and steamdb.info are invaluable for gathering such intelligence.
  • •
    Forensic Value of Application Data: Even non-standard application installations, like Steam in this case, contain a wealth of forensic artifacts. Configuration files (.vdf, .acf), user data directories, and cached information can reveal installed software, user accounts, activity logs, and attempts at anti-forensics.
  • •
    Detecting Anti-Forensics: Identifying deleted files or modified directories within application data paths is crucial for detecting attempts to hide activity. Tools capable of file system journaling analysis or carving deleted data can help reconstruct such events.
