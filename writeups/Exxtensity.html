Executive Summary & Overview

This challenge focused on identifying and analyzing malicious browser extensions, a common vector for persistent access and data exfiltration. The scenario involved investigating suspicious extensions found on employee devices to ensure they were not malicious. Key tools used included Wireshark for network traffic analysis and ExtAnalysis for static analysis of extension files.

The investigation covered methods to prevent extension installations via registry keys, manual installation and debugging of extensions in Mozilla Firefox, and identifying keylogger activity by analyzing network captures and extension source code. The challenge highlighted the importance of understanding browser extension mechanisms and network forensics in detecting and mitigating threats.

Question & Answer Solutions

1. What is the name of the subkey in the registry preventing installation of browser extensions in Google Chrome?

ExtensionInstallBlacklist

Reasoning: Identified the specific registry subkey used by Google Chrome to manage blacklisted extensions, preventing their installation. This is typically found under HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Google\Chrome\ExtensionInstallBlacklist.

2. Enable installation of browser extensions in Mozilla Firefox and install the extension ‘Quote of the Day’. What is the log of the day?

Climb the Leaderboard

Reasoning: After manually enabling extension installation in Mozilla Firefox via about:debugging#/runtime/this-firefox and installing the Quote of the Day extension, the daily log was retrieved by interacting with the extension.

3. Employee’s passwords were seen on Network logs. It could be a malicious extension. Where are the key logs sent?

112.62.33.199

Reasoning: All suspicious extensions were installed, and Wireshark was used to capture network traffic while submitting credentials on the login.html page. Filtering for destination port 14693 revealed the attacker's IP address.

4. What file has the malicious keylogger code?

Utils.js

Reasoning: The malicious keylogger code was identified within the Utils.js file. This was confirmed by searching the extension's source code for the attacker's IP address (113.62.33.199) using grep -R "113.62.33.199" ./.

5. Analyze “AdBlock Plus” extension using ExtAnalysis. How many unique domains are found?

80

Reasoning: Using the ExtAnalysis tool, the AdBlock Plus extension was analyzed, revealing 80 unique domains.

Key Takeaways & Security Insights

  • •
    Network Capture Limitations: It's crucial to understand that Wireshark typically does not capture loopback traffic (traffic between applications on the same host) by default, especially for HTTP requests. This necessitates careful setup or specific configurations to monitor local application communications.
  • •
    Firefox Extension Debugging: Manually loading and debugging Firefox extensions requires navigating to about:debugging#/runtime/this-firefox. This process is essential for analyzing extensions in a live session, especially when monitoring network activity or console logs. The manifest.json file must be specified during the loading process.
  • •
    Browser Developer Tools for Analysis: Effective analysis of browser extensions often involves adding the extension to the browser, then using the browser's built-in developer tools (inspect element, console) to monitor its behavior, trigger functionalities, and observe any generated logs or network requests.
  • •
    Registry-Based Extension Control: Operating systems provide mechanisms to control browser extension installations via the registry. For example, Google Chrome uses HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Google\Chrome\ExtensionInstallBlocklist, Microsoft Edge uses HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Edge\ExtensionInstallBlocklist, and Mozilla Firefox uses HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Mozilla\Firefox\ExtensionSettings\* to manage extension policies. These are critical for enterprise security.
