Executive Summary & Overview

This writeup details the analysis of a malicious document containing a multi-layered obfuscated macro. The challenge involved dissecting the macro's execution flow, identifying various encryption and compression techniques, and ultimately extracting critical indicators of compromise (IOCs), specifically a Command and Control (C2) IP address.

The analysis process required sequential decryption of Base64 encoded PowerShell, decompression of Gzip archives, and finally, XOR decryption of a byte array. This exercise highlights common tactics used by adversaries to evade detection and deliver payloads.

Key Takeaways & Security Insights

  • •
    Multi-Layered Obfuscation: Adversaries frequently employ multiple layers of encoding, encryption, and compression to hide their malicious payloads and evade static analysis. A thorough analysis requires systematically peeling back each layer.
  • •
    Common Techniques: Techniques like Base64 encoding, Gzip compression, and XOR encryption are prevalent in malware. Familiarity with these methods is crucial for reverse engineering.
  • •
    Macro Security: Malicious macros remain a significant threat vector. Organizations should implement strict policies regarding macro execution, including disabling them by default or only allowing digitally signed macros from trusted publishers.
  • •
    Indicator Extraction: The primary goal of such analysis is to extract actionable intelligence, such as C2 IP addresses, domains, or file hashes, which can then be used for detection and blocking on network and endpoint security devices.
